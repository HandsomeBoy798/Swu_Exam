# 西南大学课程资料库（Swu_Exam）

按学院、课程整理的学习与期末复习资料。历史试卷、往届经验和参考答案可能存在错误，课程安排与考核方式以当学期通知为准。

## 目录

- [通识必修及选修课程资料](%E9%80%9A%E8%AF%86%E5%BF%85%E4%BF%AE%E5%8F%8A%E9%80%89%E4%BF%AE%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99)：保留已有的习思想、毛概资料。
- [各学院课程资料](%E5%90%84%E5%AD%A6%E9%99%A2%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99)：沿用现有 30 个学院目录。
- [计算机与信息科学学院·软件学院](%E5%90%84%E5%AD%A6%E9%99%A2%E8%AF%BE%E7%A8%8B%E8%B5%84%E6%96%99/%E8%AE%A1%E7%AE%97%E6%9C%BA%E4%B8%8E%E4%BF%A1%E6%81%AF%E7%A7%91%E5%AD%A6%E5%AD%A6%E9%99%A2%C2%B7%E8%BD%AF%E4%BB%B6%E5%AD%A6%E9%99%A2)：39 门课程，统一按下列方式分类。

```text
各学院课程资料/
└── 计算机与信息科学学院·软件学院/
    └── 课程名称/
        ├── 复习资料/
        └── exam/
```

`复习资料` 收录课件、笔记、知识总结、复习重点、模板以及作业与实验；作业、实验和课程项目保留在 `复习资料/作业与实验/` 中。`exam` 收录历年试卷、模拟题、试题库、答案和考试回忆。源文件夹虽然叫 exam，但内容实际是知识总结的，已归入复习资料。原文件名与项目内部层级尽量保留，不改写原始文件内容。

只保留本页一个 README。空目录使用 `.gitkeep` 占位；没有试卷的课程不编造试卷。年级和学期仅表示参考库原来的归档方式。
