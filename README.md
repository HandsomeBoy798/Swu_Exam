## 怎样整理课程资料

通识课程放入对应的必修或选修目录；专业课程按开课学院归档，再建立课程名称文件夹。同一课程如供多个专业使用，优先维护一份资料，并在说明中注明适用专业与培养方案。

每门课程建议按需要设置以下内容，无资料时不必创建空子目录：

```text
课程名称/
├── README.md          课程说明、适用范围、资料来源
├── 复习资料/
├── 往年试题/
├── 考场回忆/
└── 作业与练习/
```

提交资料时，请说明课程名称、适用学年学期及资料类型；往年原题、学生回忆、个人模拟题分别标注，参考答案注明来源或整理者。已有同类资料时，可补充或订正，避免重复上传。
