## 项目介绍

Swu_Exam 是面向**西南大学同学**的课程学习与考试备考资料库。我们希望把分散的课件、笔记、复习总结、往届试卷和学习经验整理起来，让大家平时有资料可学，考前有方向可复习，也让愿意分享的同学有一个长期保存资料的地方。

本项目分为**通识课程**和**各学院课程**两个模块，欢迎来自西大各个学院、各个专业的同学一起建设。

> 🤝 **来源说明：本项目计信院模块的部分资料参考、借鉴并整理自 [SambacFeng/SWU-SE-HELPER](https://github.com/SambacFeng/SWU-SE-HELPER)。** 感谢原仓库维护者和资料贡献者。相关资料已按本项目的学院、课程结构重新归档，原作者与来源信息应予保留；详细说明见[来源与致谢](#来源与致谢)。

| 通识课程目录 | 各学院目录 | 计信院课程目录 |
| :---: | :---: | :---: |
| **5 门** | **30 个** | **39 门** |

以上是本仓库当前的目录覆盖情况，**不是学校全部学院或全部开设课程的名单**；部分课程目前只有说明或来源链接，部分目录仍待补充。

## 项目结构

```text
Swu_Exam/
├── README.md
├── 通识必修及选修课程资料/
│   └── 课程名称/
│       ├── 复习资料/
│       └── exam/
└── 各学院课程资料/
    └── 学院名称/
        └── 课程名称/
            ├── 复习资料/
            └── exam/
```

各学院目录用于汇集**学院内各专业的课程资料**，目前按课程名称查找；专业、年级、教师或教学版本存在差异时，请在资料文件名或说明中注明。

| 子文件夹 | 放什么 | 常见内容 |
| --- | --- | --- |
| **复习资料** | 日常学习和考前梳理资料 | 课件、课堂笔记、知识总结、复习提纲、参考链接、课程模板，以及作业与实验参考资料 |
| **exam** | 期末考试相关资料 | 往届试卷、模拟题、练习题库、参考答案、同学回忆版试题与考试经验 |

每门课程都保留这两个子文件夹。`待补充` 表示当前没有对应资料；空文件夹中的 `.gitkeep` 仅用于保留目录。课程项目和实验资料一般放在 `复习资料/作业与实验/` 中。

### 方法一：Fork 后提交 Pull Request

1. 点击本仓库右上角 **Fork**，创建一份自己的仓库副本。
2. 在自己的副本中创建一个分支，进入对应的“学院 / 课程 / 复习资料或 exam”目录。
3. 点击 **Add file → Upload files** 上传文件；也可以使用 Git 或 GitHub Desktop 提交。
4. 检查目录、文件名和说明，提交修改。新增课程时，请同时保留 `复习资料` 与 `exam` 两个子文件夹。
5. 发起 **Pull Request（PR）**，将自己的修改提交到 `HandsomeBoy798/Swu_Exam` 的 `main` 分支，并简要说明新增内容、来源与适用范围。

**只上传到自己的 Fork 不会自动进入本仓库，还需要提交 PR，待维护者审核合并。** 不熟悉操作时，可参考 [GitHub 官方上传文件指南](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository) 和 [从 Fork 发起 PR 的说明](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork)。

### 方法二：Issue 或邮件

不熟悉 GitHub 操作，也可以通过 [Issue](https://github.com/HandsomeBoy798/Swu_Exam/issues/new) 提供资料说明和可访问的文件链接，或发送邮件到 **[luffy798@email.swu.edu.cn](mailto:luffy798@email.swu.edu.cn)**，由维护者协助整理。邮件主题建议使用：`Swu_Exam 资料贡献｜学院｜课程`。

希望匿名贡献时，请明确写明“匿名”，并在发送前检查文件及文件属性中是否含有个人信息。署名贡献可提供希望展示的昵称或 GitHub 用户名。

### 整理与命名建议

- **注明范围：** 尽量说明学院、专业、课程、学年学期、资料类型和来源；不确定的内容标注“待核实”，个人回忆标注“回忆版”。
- **文件名清楚：** 可采用 `学年学期_课程名_资料类型_版本或署名`。例如：`2024-2025-2_软件测试_期末试题_回忆版_匿名.pdf`。
- **保持目录：** 沿用已有学院和课程名称，避免同一课程重复建目录。本仓库仅根目录保留 README；课程说明、来源链接可放入对应子文件夹中的 `课程说明.md` 或 `资料来源.md`。
- **尊重来源：** 只贡献自己有权公开分享的内容，保留原作者署名和来源；不要上传未获授权的完整商业教材、账号口令或不必要的个人信息。
- **大文件处理：** GitHub 网页上传的单文件上限为 **25 MiB**，通过 Git 提交的普通单文件上限为 **100 MiB**。较大的资料建议先通过 Issue 或邮件沟通，以来源链接等方式整理；具体限制见 [GitHub 官方说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。
