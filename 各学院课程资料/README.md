## 名单依据与命名说明

名单于2026年11月11日核对，主要依据[西南大学官网教学科研目录](https://swu.edu.cn/zzjg/jxky.htm)，并与[研究生招生网院系链接](https://yz.swu.edu.cn/lxwm/yxlj.htm)交叉核对；继续教育学院补充自[官网管理服务目录](https://swu.edu.cn/zzjg/glfw.htm)。

本目录共39个资料入口，包含学院、教育学部、心理学部及特色培养单位；这是本仓库的入口数量，不是学校独立学院总数。人文学部等学科统筹学部，以及研究所、研究中心和实验室，未单独列作学院目录。

官网同一条目并列的名称统一建立一个入口：历史文化学院·民族学院、计算机与信息科学学院·软件学院、药学院·中医药学院。文件夹使用间隔号连接名称，以避免斜杠被识别成多级路径。

袁隆平书院（创新创业学院、含弘学院、智慧农业学院）沿用[该单位官网的完整名称](https://ylpsy.swu.edu.cn/)，统一收录相关特色培养课程。体育学院目录不把体委另设为学院。

后续如学院更名、合并或新设，请根据学校正式信息更新名称，并为已有课程保留清晰的迁移说明。
